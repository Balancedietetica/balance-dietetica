# Balance dietética

Sitio estático para GitHub Pages. Cada push a `main` publica el contenido de esta carpeta.

## Publicación

En la configuración del repositorio, seleccionar **Settings → Pages → Source: GitHub Actions**. El workflow de `.github/workflows/deploy-pages.yml` se ocupa del despliegue.

## Catálogo editable

Los cambios hechos desde la página se guardan en `localStorage` del navegador y dispositivo que los realiza. No se sincronizan con los demás visitantes.
